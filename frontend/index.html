🎯 Tujuan Sistem

Wattwise adalah platform analitik energi berbasis Machine Learning yang dirancang untuk membantu industri mengidentifikasi pemborosan listrik dan mendapatkan rekomendasi efisiensi yang spesifik, terukur, dan dapat langsung dieksekusi.

Sumber
DAEWOO Steel Co. Ltd, Korea Selatan
Periode
Januari – Desember 2018
Total Record
8,600+ data point
Interval
15 menit per record

KMeans Clustering (K=3) Content-Based Filtering RobustScaler Cosine Similarity Gap Analysis Flask API
